## How to Install

### Using Docker

Pull the latest docker image

```bash
docker pull ghcr.io/dgcgovkh/document-encryption-server:latest
```

Run the docker container

```bash
docker run -d -p 8080:80 --restart unless-stopped -v ./<server-config-file>:/app/server-config.json ghcr.io/dgcgovkh/document-encryption-server:latest
```

### Non-Docker

Requirements:

- [Node.js](https://nodejs.org/en/download/)
- [npm](https://docs.npmjs.com/cli/)
- [Git](https://git-scm.com/downloads)
- [pm2](https://pm2.keymetrics.io/) - For running in the background

```bash
# Clone, install dependencies and build
git clone https://github.com/dgcgovkh/document-encryption-server.git
cd document-encryption-server
npm install
npm run build
```

Create an .env file (optinal)

```bash
# Add env variable name PORT to .env file (default port is 80)
echo "PORT=8080" >> .env
```

```bash
# Option 1. Try it
npm start

# (Recommended) Option 2. Run in the background using PM2
pm2 start dist/server.mjs --name document-encryption
```

Document-encryption is now running on http://localhost:8080

More useful PM2 Commands

```bash
# If you want to see the current console output
pm2 monit

# If you want to add it to startup
pm2 save && pm2 startup
```

## Development

The server is written in TypeScript under `src/` and compiles to `dist/`.

```bash
npm run build          # bundle to dist/ with tsdown
npm run typecheck      # type-check src and test
npm test               # run the test suite
npm run test:coverage  # run with a coverage report
```

Tests live in `test/`. `test/fixtures/oa-encryption-vectors.json` holds ciphertexts
generated by `@govtechsg/oa-encryption`; they pin the wire format so documents
encrypted by earlier releases keep decrypting.
